# Calculator

`Calculator` is a Python-based graphical calculator that allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division. It uses the Tkinter library to provide an interactive and user-friendly graphical interface.

## Features

- **Graphical User Interface (GUI)**: The calculator is equipped with a simple GUI built using Tkinter.
- **Basic Operations**: Supports fundamental arithmetic operations (addition, subtraction, multiplication, and division).
- **Clear Function**: Includes a button to clear the current input and reset the calculator.
- **Easy-to-Use Buttons**: Provides interactive buttons for numbers and operations.

## Requirements

- Python 3.x
- Tkinter library (usually included with Python)

## Usage

1. Run the `calculator.py` script to open the calculator application.
2. Use the number buttons to input numbers.
3. Select the desired arithmetic operation (addition, subtraction, multiplication, or division).
4. Click the `=` button to compute the result.
5. Use the `Clear` button to reset the input field.

## Example

To use the calculator:

- Click numbers to enter values.
- Choose the operation (e.g., `+`, `-`, `*`, `/`).
- Press `=` to get the result.
